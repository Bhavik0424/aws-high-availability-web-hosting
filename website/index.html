AWS High Availability Web Hosting

Linux • Networking • AWS • Load Balancing

Project Overview

This project demonstrates a highly available web hosting infrastructure built using AWS, Amazon Linux, networking components and an Application Load Balancer.

AWS Services Used

Amazon VPC

Custom network infrastructure.

Amazon EC2

Two Linux web servers.

Application Load Balancer

Distributes incoming traffic.

Security Groups

Controls network access.

Amazon Linux

Server operating system.

Apache

Web server hosting the application.

High Availability

Two web servers were deployed in separate Availability Zones. An Application Load Balancer distributed HTTP traffic between the servers.


During testing, one EC2 instance was stopped and the website remained accessible through the remaining healthy server.
